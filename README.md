# insta-bot-follower
A Selenium based instagram following bot
A key aspect to keep in mind is that this is only for the demonstration purpose of "Selenium knowledge" and mass bot following can lead to account being blocked/restricted.
Instagram regularly updates their UI and the xpath and the CSS selectors are subjected to change and therefore this exact same code might not work 
Only the css selectors and xpaths , names and number of followers  are subjected to change, chamge them accordingly to run the script
In case a captcha pops up, manually solve it and press enter in idleshell
## Requirements

- Python 3
- Selenium
- Google Chrome
- ChromeDriver
Install Selenium:

```bash
pip install selenium
```

## Running

```bash
python your_script_name.py
```
